Authava Chatbot Widget — Sample Integration

Drive the embedded widget from this page's controls. Status: Waiting for widget…

Show or hide the widget

Calls client.open() and client.close().

Send a message as the visitor

Calls client.sendMessage(text). If the widget is closed, it opens first so the visitor actually sees the message appear and the bot's reply stream in.

Show / hide the launcher tooltip

Calls client.showTooltip(text) and client.hideTooltip(). The tooltip only appears when the widget is closed; click Hide Bot Window first to see it in action.

Replace the disclaimer

Calls client.setDisclaimer(text) and client.clearDisclaimer(). Setting a new disclaimer clears the per-tenant "accepted" flag so the banner re-shows even for a returning visitor.

Update the preset-question chips

Calls client.setPresetQuestions(lines) and client.clearPresetQuestions(). One question per line.
